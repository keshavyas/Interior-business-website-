# Minal Interiors — React Project

Luxury Interior Design Studio website built with React, Vite, and Tailwind CSS.

## Getting Started

1. Unzip the project folder:
   ```bash
   unzip minal-interiors-react.zip
   cd minal-interiors
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Place your hero background video into the `public/` directory (or `public/videos/hero.mp4` / `public/13470979_1920_1080_24fps.mp4`).

5. Build for production:
   ```bash
   npm run build
   ```
